A Python application that analyses transactions and flags the suspicious ones in an interactive dashboard.

## How it is organised

- A transaction generator that feeds the system with test data.
- A data processing module built on pandas.
- The fraud detector, based on scikit-learn.
- An alert system and a Streamlit dashboard with Plotly charts.
